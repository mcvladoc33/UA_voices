# 🇺🇦 UA_voices — Локальний Системний Синтез Мовлення (StyleTTS2 UA)

Мінімалістичний консольний скрипт для високоякісного озвучення тексту українською мовою в повному офлайн-режимі. Проєкт використовує архітектуру **StyleTTS2** для синтезу голосу та нейромережу **mBART** для інтелектуального відмінювання чисел, скорочень і знаків відсотків відповідно до контексту речення.

Вся робота програми, файли моделей та логіка ізольовані всередині однієї папки проєкту і не забивають глобальний cache системи.

## 📋 Вимоги до системи

* **Python: 3.11** (Рекомендовано для повної сумісності з усіма залежностями звукових карт та PyTorch).
* **ОС:** Windows / Linux / macOS.

## 📦 Встановлення

1. Клонуйте цей репозиторій або завантажте файли в окрему теку.
2. Створіть та активуйте віртуальне середовище (переконайтеся, що використовується Python 3.11):

**Windows:**

```bash
python -m venv .venv
.venv\Scripts\activate

```

**Linux / macOS:**

```bash
python3.11 -m venv .venv
source .venv/bin/activate

```

3. Встановіть необхідні залежності:

```bash
pip install -r requirements.txt

```

## 🚚 Завантаження моделей (Один раз)

Щоб скрипт міг працювати без доступу до інтернету, викачайте потрібні нейромережеві ваги безпосередньо у теку проєкту, запустивши скрипт:

```bash
python download_models.py

```

Він створить директорію `models/` та збереже туди близько 3.5 ГБ файлів конфігурацій та ваг.

## 🗣️ Налаштування голосу

Покладіть ваш `.pt` файл пресету голосу (наприклад, `Інна Гелевера.pt`) всередину папки `voices/` у корені проєкту:

```text
└── UA_voices/
    ├── voices/
    │   └── Інна Гелевера.pt

```

## 🚀 Запуск та використання

Запустіть головний скрипт у терміналі:

```bash
python voice_console.py

```

Після ініціалізації моделей (яка відбувається виключно з диска в RAM вашого ПК) ви зможете вводити будь-які речення українською мовою:

**Приклад роботи:**

```text
Введіть текст українською (або 'exit' для виходу): у 1928 році
Робота вербалізатора...
[Оброблений текст]: У тисяча дев'ятсот двадцять восьмому році
🔊 Озвучую...

```

Для виходу з програми введіть `exit`.

## 🔒 Повна ізоляція (Офлайн режим)

У коді примусово увімкнені прапорці `HF_HUB_OFFLINE=1` та `TRANSFORMERS_OFFLINE=1`. Скрипт гарантовано запуститься і буде синтезувати мовлення навіть при повному фізичному вимкненні інтернету на вашому комп'ютері.
