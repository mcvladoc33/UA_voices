# UA_voices — Локальний Системний Синтез Мовлення (StyleTTS2 UA)

Мінімалістичний консольний скрипт для високоякісного озвучення тексту українською мовою в повному офлайн-режимі. Проєкт використовує архітектуру **StyleTTS2** для природного синтезу голосу та нейромережу **mBART** для інтелектуального відмінювання чисел, дат, скорочень і знаків відсотків відповідно до контексту речення.

Вся робота програми, файли моделей, медіа-кодеки та вихідні результати ізольовані всередині однієї папки проєкту і не засмічують глобальний cache операційної системи.

## 📋 Вимоги до системи

* **Python: 3.11** (Рекомендовано для повної сумісності з усіма залежностями звукових карт та PyTorch).
* **ОС:** Windows / Linux / macOS.
* **FFmpeg:** Бінарні файли (`ffmpeg.exe`, `ffprobe.exe`) мають знаходитися в папці `bin/` у корені проєкту для коректної збірки MP3.

## 📦 Встановлення

1. Клонуйте цей репозиторій або завантажте файли в окрему теку.
2. Створіть та активуйте віртуальне середовище:

**Windows:**
```bash
python -m venv .venv
.venv\Scripts\activate

```

**Linux / macOS:**

```bash
python3.11 -m venv .venv
source .venv/bin/activate

```

3. Встановіть необхідні залежності (включаючи оптимізовану роботу зі звуком):

```bash
pip install -r requirements.txt --no-cache-dir

```

*(Примітка: якщо ви раніше встановлювали інші версії пакетів, виконайте `pip cache purge` перед інсталяцією).*

## 🚚 Завантаження моделей (Один раз)

Щоб скрипт міг працювати без доступу до інтернету, викачайте потрібні нейромережеві ваги безпосередньо у тему проєкту, запустивши скрипт:

```bash
python download_models.py

```

Він створить директорію `models/` та збереже туди близько 3.5 ГБ файлів конфігурацій та ваг моделей StyleTTS2 та mBART.

## ⚙️ Налаштування та Конфігурація (`config.json`)

Керування логікою роботи, голосами та швидкістю мовлення відбувається через файл `config.json` у корені проєкту. Створіть його перед першим запуском.

### Приклад конфігурації:

```json
{
  "mode": "2",
  "preset_filename": "Інна Гелевера.pt",
  "reference_filename": "sample.wav",
  "speed": 1.0,
  "noise_scale": 0.1,
  "match_duration": true,
  "use_verbalizer": true
}

```

### Повне пояснення параметрів:

* **`mode`** (`string`, дефолт: `"1"`)
Режим роботи синтезу мовлення:
* `"1"` — **Режим пресету**: використовує готовий зліпок голосу у форматі `.pt`.
* `"2"` — **Режим клонування**: миттєво копіює голос із короткого аудіофайлу `.wav`.


* **`preset_filename`** (`string`, дефолт: `"Інна Гелевера.pt"`)
Ім'я файлу готового голосу, який лежить у папці `voices/`. Використовується лише якщо параметр `mode` виставлено в `"1"`.
* **`reference_filename`** (`string`, дефолт: `"sample.wav"`)
Ім'я аудіофайлу-донора з папки `references/`, чий голос буде скопійовано. Використовується лише якщо параметр `mode` виставлено в `"2"`.
* **`speed`** (`float`, дефолт: `1.0`)
Базова швидкість вимови тексту. `1.0` — стандартний темп, `0.9` — трохи повільніше, `1.1` — швидше.
* **`noise_scale`** (`float`, дефолт: `0.1`)
Рівень ШІ-варіативності інтонацій. Значення `0.0` робить голос стабільним, але монотонним, а `0.1`–`0.2` додає живої, природної експресії.
* **`match_duration`** (`boolean`, дефолт: `false`)
Автоматичне підлаштування темпу мовлення (`true` / `false`). Якщо увімкнено, ШІ намагатиметься вимовити новий текст із тією ж швидкістю та таймінгами, що й оригінальний файл-референс (працює тільки для `mode: "2"`).
* **`use_verbalizer`** (`boolean`, дефолт: `true`)
Активація мовної підсистеми (`true` / `false`). Якщо вибрано `true`, задіюється важка нейромережа mBART для інтелектуального читання чисел з урахуванням контексту. Якщо `false` — її буде вимкнено для заощадження ~2 ГБ оперативної пам'яті (увімкнеться швидка алгоритмічна заміна).

## 🗣️ Підготовка матеріалів голосу

Залежно від обраного `mode` у конфігурації, програма шукає файли за такими шляхами:

* **Для Режиму Пресету (`mode: "1"`):** Покладіть ваш `.pt` файл пресету всередину папки `voices/`.
* **Для Режиму Клонування (`mode: "2"`):** Покладіть короткий чистий запис голосу (16-bit WAV, моно, бажано без шумів та музики) всередину папки `references/`.

```text
└── UA_voices/
    ├── bin/                # Папка з ffmpeg.exe та ffprobe.exe
    ├── voices/             # Папка для пресетів голосу (.pt)
    │   └── Інна Гелевера.pt
    └── references/         # Папка для аудіо-референсів клонування (.wav)
        └── sample.wav

```

## 🚀 Запуск та отримання результатів

Запустіть головний скрипт у терміналі:

```bash
python voice_console.py

```

Після швидкої ініціалізації моделей з диска ви зможете вводити будь-які речення українською мовою. Скрипт автоматично ізолює речення з цифрами, захищаючи генерацію від мовних галюцинацій та циклічних "хвостів" ШІ.

**Приклад сесії роботи:**

```text
Введіть текст українською (або 'exit' для виходу): Привітик від Advel. Нейронка озвучує це 17.05.2026.
[Текст для ШІ]: Привітик від Адвел. Нейронка озвучує це сімнадцятого травня дві тисячі двадцять шостого року.
🔊 Озвучую...
💾 Файли успішно створено в 'outputs/':
   └─ output.wav
   └─ output.mp3

```

### 📁 Куди зберігається аудіо?

Програма автоматично створює в корені теку **`outputs/`**. Кожна репліка зберігається туди одночасно у двох форматах:

1. `output.wav` — оригінальний звук максимальної студійної якості (32-bit Float, 24kHz).
2. `output.mp3` — оптимізований, стиснутий і очищений від цифрового тріску аудіофайл (16-bit signed int, 192kbps), ідеальний для пересилання в месенджерах.

Для завершення роботи зі скриптом введіть у консоль `exit`.

## 🔒 Повна офлайн-ізоляція

У системному коді примусово увімкнені інженерні блоки блокування мережі `HF_HUB_OFFLINE=1` та `TRANSFORMERS_OFFLINE=1`. Скрипт гарантовано працюватиме і синтезуватиме мовлення навіть за повної відсутності інтернет-з'єднання на комп'ютері.
